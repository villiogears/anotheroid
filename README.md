# Anotheroid
Vite + Typescript + Vue3 + Bun.jsでAndroid上でWebAssemblyを動かそうプロジェクト

オフライン実行対応(wasmファイルの機能依存)

基本的にAndroid上でwasmを使ってGUIを描画するために作りました。
apkが多くのAndroidデバイスで使えなくなることが見込まれる中、GUIでアプリを使えるようにする方法は他にないかと思い作成しました。
wasmとして実行するためのアプリなので、ブラウザとしてのアプリのように思われるかもしれません。たしかにブラウザっぽいし、Androidのネイティブアプリほどできることは多くないです。それは逆に言えば、Androidの根幹となるシステムのバグを踏みにくいなどのメリットが有るのでは無いかと思っています。
